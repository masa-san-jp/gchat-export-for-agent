# gchat-export-for-agent

Google Chat のやりとりをエージェント処理向けに書き出すツールです。  
A tool for exporting Google Chat conversations for agent-oriented workflows.

## 概要

この README は、このリポジトリの役割を示すための最小 README です。
詳細な使い方、設計、運用ルールが必要な場合は今後追加します。


## 用語と利用例

「エクスポート」は Chat のメッセージを別の処理から読める JSON に書き出すこと、「差分同期」は前回の取得時刻より新しいメッセージを取得して既存JSONへ加えることです。たとえば架空のスペース `spaces/XXXXXXX` の会話を `chat_XXXXXXX.json` に保存し、エージェントが議論の経緯を参照する入力として使います。保存対象は `id`、`sender`、`text`、`createTime`、`thread` です。

## 設計の考え方・技術的背景

[設計仕様書](docs/design.md)の目的は、同じ会話履歴をクラウド・ローカル双方のエージェントから参照できる状態にすることです。想定構成は Google Chat REST API → Google Apps Script（GAS）→ Google Drive のJSON → 必要に応じて Drive for Desktop です。

[GASテンプレート](docs/gas-template.md)は `syncAllSpaces()` から対象スペースを順に処理し、`PropertiesService` に取得時刻を保存します。ページ送りで取得したメッセージをIDで統合し、作成日時順に並べます。対象スペースと保存先は利用者が明示設定します。Chat の読み取り権限とは別に、Driveの出力先と共有範囲の確認も必要です。

## 現在地と背景

現在のリポジトリは README、設計仕様書、Markdown内のGASテンプレートから成る設計・導入用資料です。独立した配布アプリや、稼働中の同期サービスを提供するものではありません。背景は設計書の「AIエージェントがローカル・クラウド双方から参照できる状態を維持する」という要件にあります。成立日や実運用の履歴は資料からは確認できないため、ここでは断定しません。

## 導入と展開

まず設計仕様書の設定・権限を確認し、テンプレートをGASへ移して対象スペース、保存先、時間トリガーを設定する流れを想定しています。実行前に少数のテストデータで取得結果を確認してください。新規作成時刻を条件にするテンプレートのため、既存メッセージの編集・削除を完全に同期する仕組みではありません。

添付ファイル・リアクション取得、Markdown変換、スペース自動検出は [設計書 §9](docs/design.md#9-拡張ポイント) の拡張候補で、現テンプレートでは実装されていません。導入後の要約や検索は、出力JSONを読む側のエージェントで行う範囲です。
